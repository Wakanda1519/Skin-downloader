# 🎮 Skin downloader

**CLI-утилита для Rust Devblog комьюнити, которая парсит декомпилированные исходники Rust.Workshop.dll, группирует SkinID по Shortname и скачивает весь скинпак с помощью SteamCMD**

## Особенности

* Автоматическая установка SteamCMD, если он не найден рядом или в PATH.
* Докачка прерванной загрузки: уже скачанные скины пропускаются.
* Параллельная загрузка в несколько воркеров SteamCMD и автоматические повторы ошибок.
* Итоговая сверка с диском: предложит докачать недостающие или удалить их из итогового json.
* Группировка скинов по shortname предметов в формате json.

> **Важно:** в `Rust.Workshop.dll` хранится полный список скинов, которые были доступны в Steam Workshop на момент релиза девблога. Поэтому скачанный набор соответствует именно той версии игры, из которой взят этот файл.

## Установка

### Требования

* Windows 10+
* Go 1.26+
* Декомпилированные исходники `Rust.Workshop.dll`.
* SteamCMD отдельно ставить не нужно: утилита скачает его сама.

### Сборка

```
go build -o Skindl.exe .
```

### Использование

1. Создайте папку, перенесите туда `Skindl.exe` и запустите.
2. `Skindl.exe` создаст папку source, туда надо перенести декомпилированные исходники `Rust.Workshop.dll`. В папке с игрой dll хранится по пути `...\RustClient_Data\Managed\Rust.Workshop.dll`, для декомпиляции можно использовать `ILSpy` (Загружаете dll, ПКМ по ней в интерфейсе программы, кликаем "Save Code...", сохраняем в папку source), нажмите Enter
3. Дальше программа сделает всё за вас, сначала сформирует файл `Skins.json`, потом начинает скачивать скины с Steam Workshop, в конце предложит повторить установку скинов с ошибкой или удалить их из json.

## Что делать с полученными файлами?

* `Skins.json` можно перенести в конфиг вашего плагина, который работает со скинами, к примеру `XSkinMenu.cs`.
* Можно модифицировать клиент, чтобы скины брались не из Steam, а из папки workshop, которая будет в директории игры.
